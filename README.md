# About This Project:

This project is a simple Housing Price Prediction model, built as part of my Data Science course by CodeWithHarry.

The goal of this project is to predict housing prices using basic machine learning techniques. I’ve used scikit-learn, NumPy, pandas, and joblib to train and save the model efficiently.

Once you install the required dependencies from requirements.txt, you can run the Python script to:

Train the model on the housing dataset

Automatically save the trained model and data pipeline as model.pkl and pipeline.pkl

Dataset used: https://www.kaggle.com/datasets/camnugent/california-housing-prices (California Housing Prices)

## How to Run
- Install dependencies:
- pip install -r requirements.txt
- Run python file

You have to run the file second time to get your Predictions(predictions.csv) as the first time the model was Trained without predicting. You can also compare the prices of the prediction.csv with the original test set (test_set.csv)
